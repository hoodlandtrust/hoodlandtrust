# HOOD Community Land Trust website

This is a static website for HOOD Community Land Trust. It uses plain HTML, CSS, and JavaScript, so it can be hosted on GitHub Pages without a build step.

## Preview it

Open `index.html` in a web browser. For the most accurate preview, serve the folder with any simple local web server.

## Publish with GitHub Pages

1. Create a new public GitHub repository, such as `hood-community-land-trust`.
2. Upload everything inside this `website` folder to the root of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will show the public website address after deployment finishes.

## Before public launch

- Add a public HOOD email address or contact-form service once one is approved.
- Confirm that the mailing address and organization-status statement are current.
- Replace or expand the “Where we are now” section as HOOD acquires sites or opens programs.
- Add a custom domain later through GitHub Pages if desired.

## Files

- `index.html` — site content and page structure
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation, scroll effects, and address-copy button
- `.nojekyll` — tells GitHub Pages to serve the site exactly as provided
- `assets/` — original website photography generated for HOOD

The site has no analytics, cookies, external fonts, trackers, or third-party code.
